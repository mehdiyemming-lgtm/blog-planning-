
# Blog de classe 
## Cartographier le SDLC 
### Analyse des besoins 
```bash
le site doit permettre aux élèves de publier des articles, les commenter, creer un compte et s'y connecter.
Seul les personnes ayant des comptes peuvents publier et commenter
```
### Design 
```bash
Un site simple et leger
```
### test 
```bash
Lors des tests verifier que seul les élèves connecter peuvent publier et commenter
```
### Maintenance 
```bash
Se preparer à acceuillir plus d'élèves,
gérer les bug
```
### Methodologie 
```bash
la methode Agile convient le mieux ici car elle s'adaptera facilement au nombres d'utilisateur croissants
```
## Wireframe 
1. En tant que élève, je veux partager mes difficultés rencontrées, afin de pouvoir récolter des suggestions pour les surmonter
2. Besoins fonctionnels et non-fonctionnels
   - Besoins fonctionnels : poster, commenter, se connecter
   - Besoins non-fonctionnels
3. SRS
   - Ce site existe pour connecter les élèves entre eux et leur permettre de partager leurs expériences
   - On doit inclure la gestion des comptes, l'ajout de commentaires, la publication d'articles ; on ne doit pas trouver de système de messagerie privée, ni d'abonnements
   - Besoins fonctionnels :
     - Se connecter à son compte
     - Poster des articles
     - Commenter des articles
